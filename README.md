# クローゼット

スマートフォンで「何が何個あるか」をすぐ確認できる、シンプルなクローゼット管理 PWA です。データはブラウザの `localStorage` に保存され、サーバーやアカウントは必要ありません。

アプリアイコンを含むすべてのファイルは、GitHub上で差分を確認できるテキスト形式です。画像アイコンにはバイナリのPNGではなくSVGを使用しています。

## 使い方

`index.html` を静的 Web サーバーで配信してください。品目名と個数を入力して「追加」を押すと登録できます。同名の品目は既存の個数に加算されます。

カテゴリは画面上部で作成できます。品目の追加時または各カードの「編集」から複数のカテゴリを設定でき、上部のカテゴリチップで表示を絞り込めます。カテゴリを設定しないままでも品目を登録できます。

品目とカテゴリはブラウザの `localStorage` に保存されます。以前のバージョンで登録したカテゴリ情報のない品目もそのまま読み込まれ、「編集」から後でカテゴリを設定できます。

## バックアップと復元

画面下部の「バックアップをコピー」を押すと、すべての品目・個数・カテゴリ設定をJSON形式でクリップボードへコピーします。「バックアップを読み込む」の入力欄へJSONを貼り付けると、内容を確認してから復元できます。不正なJSONは読み込まず、現在のデータを保持します。

iPhoneでは、Safari版でバックアップをコピーし、ホーム画面版の入力欄を長押しして貼り付けることでデータを移行できます。復元すると移行先に現在保存されているデータはバックアップの内容に置き換わるため、必要に応じて先に移行先のバックアップも保存してください。

## GitHub Pages で公開する

1. この一式を GitHub リポジトリのルートへ push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の Source で **Deploy from a branch** を選びます。
4. 公開するブランチ（通常は `main`）と **/(root)** を選んで **Save** を押します。
5. 表示された公開 URL を iPhone の Safari で開き、共有メニューから **ホーム画面に追加** を選びます。

> ブラウザごと・公開 URL ごとに別のデータとして保存されます。Safari のサイトデータを削除すると登録内容も消えるためご注意ください。

## ローカルで確認する

Service Worker は `file://` では動かないため、ローカルサーバーを使います。

```sh
python3 -m http.server 8000
```

その後、<http://localhost:8000> を開いてください。
